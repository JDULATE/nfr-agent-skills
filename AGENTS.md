# Using nfr-agent-skills

This repository contains 114 agent skills for Non-Functional Requirements (NFRs).
Use them to turn project concerns into scoped implementation and verification work.

## Choose and read a skill

1. Browse [INDEX.md](INDEX.md) for candidate skills and their status.
2. Use the [disambiguation map](references/disambiguation-map.md) to distinguish siblings.
3. Before planning or building, read the relevant `skills/NNN-slug/SKILL.md` in full.
4. Follow that skill's Workflow. Inspect the project's code and docs as directed;
   read its linked references when their guidance applies.

## Apply the skill

- Ask at most three essential questions; use the request and inspected project
  evidence to resolve decisions that do not need a user answer.
- State assumptions and proposed defaults before building. Keep unknown decisions
  explicit, and confirm illustrative numeric targets with the user/stakeholder.
- Build the smallest version that meets the request. Offer larger extensions
  separately and obtain the user's yes before adding them unless already authorized.
- Perform the relevant verification. Report what changed, what was verified,
  what was not verified, and any unresolved assumptions or limitations.

The phased authoring process does not apply to using these skills on a project.
