# Standards allowlist

Read when deciding whether a skill may name an external standard.

Source boundary: the user supplied the titles below and authorized checks against
publisher pages for this Phase 2 review. The title wording was checked against
ISO, W3C, and OWASP publisher pages. ISO title separators below match the
publishers' em dashes. W3C is the publisher of the WCAG title, not part of its
title; its version remains to be confirmed. ASVS is the acronym for the OWASP
title. Publisher links stay in the agent's session notes, outside the repository.
No URLs, edition years, or clause numbers are included. No edition is selected.

The five titles are verified; title-verification markers have been removed.
Edition or version selection and applicability remain unresolved. These are
candidate citations for the listed NFR ids only; their presence does not establish
a normative requirement or prove compliance. Ask the user for the applicable
edition or version and relevant source text before making a substantive
standards-based claim. Omit the claim if not confirmed. The additional restriction
on ISO/IEC 25010 below applies even if an edition is subsequently selected.

The id assignments are proposed repository citation boundaries, not assertions
that a standard defines each listed NFR. Ask the user before expanding them.
Do not infer a clause, threshold, legal duty, certification, or exact quotation
from an identifier or this table. Do not add a version suffix without review.

The current validator checks identifier and URL membership, not these per-id
permissions or review decisions. Authors and reviewers must check those manually.
An automated pass does not establish an edition choice or applicability.
