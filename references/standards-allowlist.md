# Standards allowlist

Read when deciding whether a skill may name an external standard.

Source boundary: the current Phase 2 instructions supply the identifiers and
broad scopes below, but do not supply exact titles, editions, clauses, or source
documents. No external sources have been consulted. Exact titles are therefore
explicitly unresolved rather than reconstructed from memory. No URLs are added.

All entries are **VERIFY BY HUMAN**. They are candidate citations for the listed
NFR ids only; their presence does not establish a normative requirement or prove
compliance. Ask the user for the exact title and relevant source text before
making a substantive standards-based claim. Omit the claim if not confirmed.

The id assignments are proposed repository citation boundaries, not assertions
that a standard defines each listed NFR. Ask the user before expanding them.
Do not infer a clause, threshold, legal duty, certification, or exact quotation
from an identifier or this table. Do not add a version suffix without review.

The current validator checks identifier and URL membership, not these per-id
permissions or review decisions. Authors and reviewers must check those manually.
An automated pass does not clear a VERIFY BY HUMAN marker.
