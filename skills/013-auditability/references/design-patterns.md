# Examination practices

Select evidence for a scoped examiner question, not for an assumed universal audit checklist.

## Question-to-evidence matrix

- Use when a reviewer needs to evaluate an action, decision, exception or control.
- Trade-off: a bounded question makes evidence needs inspectable but leaves other
  questions unanswered; a generic event export can conceal those limits.
- Verify: map each required answer element to source, provenance, interpretation
  context and a gap state; do not count unrelated records as supporting evidence.

## Permitted reviewer view

- Use when evidence includes restricted fields or requires specialized interpretation.
- Trade-off: redaction and least disclosure can limit examinability; bypassing
  the approved access boundary is not an acceptable way to claim reviewer sufficiency.
- Verify: rehearse retrieval under the actual reviewer role with the approved
  schema/context and record unanswerable portions rather than using author-only knowledge.

## Gap, expiry and contradiction record

- Use when no matching events or only favorable evidence appears.
- Trade-off: retaining collection status and exceptions adds lifecycle decisions;
  without them an empty query cannot distinguish no action from missing evidence.
- Verify: exercise known actions, expiry, collection gaps and contradictory cases;
  inspect whether the answer appropriately becomes unknown rather than affirmative.

## Reproducible examination package

- Use when another reviewer must repeat a conclusion from retained evidence.
- Trade-off: frozen evidence/query context improves reproducibility but may expose
  only a specific revision/window; it is not ongoing or legal compliance by itself.
- Verify: retain scope, query/view, provenance and result limits; reproduce the
  answer without private author explanations and with the approved lifetime/access policy.
