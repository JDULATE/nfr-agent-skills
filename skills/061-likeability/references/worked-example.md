# Confirmation-flow response example

The scenario is hypothetical; no response below is an observed user statement.

## Candidate interaction and carried state

A synthetic reviewer submits `report-slate`. Both Original and Candidate must
produce the same submitted report and preserve the required final confirmation.
Original repeatedly asks for confirmation after non-final edits. Candidate keeps
confirmation only at the agreed final action; the stakeholder must approve that boundary.

| Observation to collect | Original | Candidate | Meaning |
| --- | --- | --- | --- |
| Actual result | Check submitted report | Same result check | Task success evidence |
| Assistance | Record actual help | Same support policy | Exposure context |
| Post-task feeling | Collect neutral response | Same question | Subjective evidence |
| Stated moment/reason | Record respondent's words | Record respondent's words | Possible explanation, not proven causation |

## Requirement example

Illustrative response protocol; confirm with the user/stakeholder:
After the submission task, ask the skill's anchored 5-point experience question
and retain a reason. Ask which subjective acceptance rule should govern a decision;
do not manufacture a favorable threshold or an audience preference.

## Scripted evidence rows, not participant observations

Use these invented inputs only to demonstrate how the evidence ledger behaves:
`case-slate` supplies successful submission plus a negative experience response;
retain the negative judgment and the successful result together. `case-amber`
supplies failed submission plus a positive response; retain the task failure
even though the sentiment is positive. Neither row is an audience preference result.

## Interpretation and rejection

If a user completes the task but rates the experience negatively, retain both
facts. If the candidate receives a positive response after a failed submission,
retain the task failure too; preference cannot certify valid task performance.

A screenshot-only vote would address visual appeal, not these confirmation
interruptions. A comment praising the absence of prompts cannot justify removing
an authorization check required for submission. No audience outcome is claimed.
